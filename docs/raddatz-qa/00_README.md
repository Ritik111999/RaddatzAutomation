# Raddatz QA Functional Knowledge Base

This directory is the evidence-led discovery record for the local Raddatz PWA.

## Investigation rules

- Evidence classifications: `OBSERVED`, `DOCUMENTED`, `CODE-INFERRED`, `CLIENT-CONFIRMED`, `HYPOTHESIS`, `UNKNOWN`, `RESTRICTED`, and `BLOCKED`.
- Personal, legal, financial, and document content is redacted. Records are described structurally or with synthetic identifiers only.
- Create/edit automation is permitted only for records owned by the current automation run and only outside the restricted areas below.
- Never delete records.

## Restricted from interaction and automation

- Integrations, Backend Data Controller, Portal Access, permission/role administration, authentication or access-control settings.
- External connections, secrets, API keys, import/export, bulk operations, synchronization, and migrations.
- Billing, payment, invoice finalization, financial postings, email/SMS, external sharing, and unknown high-impact controls.

## Current investigation state

The initial local UI inventory began on 2026-10-23 against the supplied local PWA. The observed role is `admin`. This is an incremental knowledge base: findings are appended only after an evidence-producing observation.
