# Function catalog

| Function | Inputs / dependencies | Consumer / outcome | Evidence |
| --- | --- | --- | --- |
| Company management | Company record | Companies & Matters lineage | RAD-E-0007 |
| Property management | Company relationship | Companies & Matters lineage, matter breadcrumb | RAD-E-0007, RAD-E-0008 |
| Matter management | Property plus tenant/case data | Matter workspace, tasks, events, timeline | RAD-E-0008, RAD-E-0009 |
| Task management | Matter, title, due date, assignee, type, priority | Dashboard, task list, matter To-do, timeline | RAD-E-0002, RAD-E-0005, RAD-E-0009 |
| Event management | Matter, schedule/category/participants/courtroom | Calendar and Court Updates selection | RAD-E-0004, RAD-E-0006 |
| Court update | Selected calendar entry, matter, notes, status | Court Update list; possible billing handoff | RAD-E-0004 |
| Document intake | Matter and file/template selection | Matter document inventory | RAD-E-0009 |
| Template management | Metadata, category, variables, Word source | Reusable document generation | RAD-E-0011 |
| Workflow automation | Trigger and action configuration | Automated task/case processes | RAD-E-0003 |

All actions marked by edit/delete/enablement controls remain excluded unless they target proven automation-owned data and are outside the restricted register.
