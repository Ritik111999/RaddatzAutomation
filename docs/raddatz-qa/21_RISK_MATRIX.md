# Risk matrix

| Area | Risk | Automation disposition | Basis |
| --- | --- | --- | --- |
| Company/property/matter | Medium | Allowed only for owned records | User-confirmed scope + RAD-E-0007/0008 |
| Tasks/events/notes | Medium | Allowed only for owned linked data | User-confirmed scope + RAD-E-0005/0006/0009 |
| Workflows | High | Observe only until trigger effects are bounded | RAD-E-0003 |
| Court Updates | High | Read-only | Billing handoff in RAD-E-0004 |
| Documents/templates/editor | High | Observe only until controlled fixture and persistence behavior are proven | RAD-E-0009/0011 |
| Billing | Critical | Restricted | User restriction |
| Client Portal / portal publishing | Critical | Restricted | User restriction |
| Bulk upload/export/import | Critical | Restricted | User restriction |
| Permissions/auth/staff/configuration | Critical | Restricted | User restriction |
| Integrations/backend data controller | Critical | Restricted | User restriction |
